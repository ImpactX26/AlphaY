Educaro Applicant Flow v2

The applicant talks and uploads. The agent builds the profile, checks it against the real requirements of the university or employer they pick, fixes gaps with Educaro's own courses and services, and sends applications once they approve. It stays with them through their first weeks in Germany. Educaro staff run the same agent from the other side.

Fixed rules in code

Sort and transcribe

Each file is classified on arrival, for example "CBSE class 12 marksheet" or "experience letter". Only the video's audio is transcribed. The picture is stored and never analysed.

Files stay on Educaro's server. Nothing personal goes into web searches.

Every sentence and every file becomes a claim with a source.

Harness

Supervisor, specialists, guards, skills

The supervisor plans, the twelve specialists run in parallel as queue jobs, and each loads the skill it needs. The guards are plain code the model cannot talk its way past:

  1. No source, no save. Web facts need a link opened in this session.
  2. Required checks cannot be skipped.
  3. CVs and letters use only Verified and You said facts.
  4. Nothing leaves the system without a human tap.
  5. Two questions at a time, never one a document already answers.
  6. Names, passport numbers and phone numbers never go into web searches.

The demo, in three minutes

One scripted path that shows every agentic moment. Seed both personas before the judges arrive.

  1. 0:00Ananya uploads a 90-second video and seven files. Her screen starts empty and fills while the files are read.
  2. 0:25The truth map lights up: the experience conflict and the name mismatch. The agent asks exactly two questions.
  3. 0:50Her screen composes itself. Switch to Rohan: a completely different screen from the same app.
  4. 1:10Rohan shortlists a programme. The matrix shows APS missing, and the plan appears with links.
  5. 1:35Ananya's German gap routes to an Educaro B1 course and an ÖSD exam at Educaro.
  6. 1:55The agent drafts a Bewerbung to a partner employer, keywords highlighted. She approves, and the mail lands in the inbox on the projector.
  7. 2:20A reply with an interview invite arrives. It goes into her calendar and pings her phone on Discord.
  8. 2:40Switch to the command centre: her card has moved to Matched, and the trace shows every source the agent opened.
